# Operación de espionaje — Versión 1.0.0

Minijuego desarrollado en Java utilizando Swing, WindowBuilder, Gson y JMapViewer.

**Contenido de esta versión**
- Aplicación Java ejecutable.
- Lectura de datos desde archivos JSON.
- Interfaz gráfica y funcionalidades principales del minijuego.
- Bibliotecas necesarias para su ejecución.

**Instrucciones**
1. Descargar el archivo ZIP.
2. Extraer su contenido.
3. Tener Java instalado.
4. Ejecutar `ejecutar.bat` desde la carpeta extraída.

Esta distribución incluye los archivos necesarios para ejecutar el minijuego en Windows.
